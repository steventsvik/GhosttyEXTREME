# Contributing

Issues and pull requests for GhosttyEXTREME's own features (vertical tabs,
agent status, code editor, agent tools, sessions) are welcome here.

Bugs that also happen in official Ghostty belong upstream: check
[ghostty-org/ghostty](https://github.com/ghostty-org/ghostty) and follow its
contributing guide. Please don't report GhosttyEXTREME issues to the Ghostty
project.

Build instructions are in the [README](README.md); Ghostty's own developer
notes are in [HACKING.md](HACKING.md).
